# MigosMC Rules 1.0.2

Создан **mlpgod** для **MigosMC**, Minecraft **1.21.11**. MigosRules запускается самостоятельно; ChatSorter для него не требуется.

## Установка и использование

1. Установите Fabric Loader для Minecraft 1.21.11 и Fabric API.
2. Поместите `migos-rules-1.0.2.jar` в папку `mods`.
3. В игре нажмите **K**. Клавишу можно изменить в меню «Настройки → Управление → Назначение клавиш», категория **MigosMC Rules**.
4. При первом открытии нажмите «Обновить». Не закрывайте игру до завершения загрузки. Окно правил можно закрыть — загрузка продолжится в фоне.

Правила загружаются с официального форума MigosMC напрямую на компьютер пользователя. Встроенной копии текстов в JAR нет. После успешной загрузки правила доступны без интернета; кнопка «Обновить» проверяет публичные разделы повторно.

Слева находятся разделы правил; «Все разделы» включает глобальный поиск. Справа отображаются пункты, примечания и наказания. Колесо мыши прокручивает список под указателем. Выберите пункт и нажмите «Копировать» или «Источник». Копирование не отправляет текст в чат.

Кэш правил хранится в `config/migosrules/migos-rules.json`. При сетевой ошибке или изменении разметки форума предыдущая копия не заменяется. Цветовая тема при необходимости настраивается отдельно в `config/migosrules/theme.properties` параметром `theme` от `0` до `4`.

Закрытые разделы и документы на других сайтах не загружаются; ссылки из правил сохраняются в тексте. Изображения представлены ссылками, их можно посмотреть на форуме через «Источник».

## Охват

Загрузчик обходит публичные разделы официальных правил и режимов, их подразделы и страницы тем. Для многостраничных тем читаются сообщения автора первого поста. Обсуждения других пользователей не включаются.

## Сборка

JDK **21**, Gradle **9.2.1**: `gradle build`. Результат: `build/libs/migos-rules-1.0.2.jar`. Jsoup включается в JAR автоматически. В `.github/workflows` предусмотрена сборка через GitHub Actions.
